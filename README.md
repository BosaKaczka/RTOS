# RTOS Laboratory Solutions

This repository contains my solutions for the Real-Time Operating Systems (RTOS) laboratory tasks completed during my Master's studies in 2026.

## Hardware Platform
The projects were developed and tested on the following hardware:
* **Raspberry Pi Zero 2 W**
* **Beam Kit 1**: The board was mounted on the [Beam Kit 1](https://github.com/jmnich/beam_kit_1) platform.

## Software & RTOS
For the real-time implementation, I utilized the **FreeRTOS** kernel.
* **Kernel Source**: [FreeRTOS-Kernel on GitHub](https://github.com/FreeRTOS/FreeRTOS-Kernel)
